# Tatevik Aleksanyan, Portfolio

My portfolio site, designed and built by me.
Live at **https://tatevik-aleksanyan.com**

## What's inside
- `site/index.html`: the whole site in one file (HTML, CSS and JavaScript)
- `site/img/`: case study images (WebP)

## How I built it
- Designed in Figma, using my own design system:
  62 variables, 25 text styles and 13 components,
  with font sizes reduced from 56 to 14 and spacing values from 27 to 10,
  plus a contrast audit.
- Built and launched the site myself.
